// working together

AI in development. From design to operation.

I help teams put AI to work on real software. I start with a specific problem, the existing code and a measurable definition of success.

01

Agentic system design

I design how AI agents work together: their roles, context, tools, permissions and handoffs. This includes supervision, recovery from errors and decisions that remain with people.

Deliverable: architecture, a validated prototype and an integration plan.

02

Software development automation

I connect requirements to implementation, code review, tests, CI/CD and deployment. I build repeatable workflows for new features, maintenance and modernizing existing applications.

Deliverable: a working development workflow with quality checks.

03

AI integration and verification

I connect agents to repositories, APIs and business tools, including through MCP. I set up checks for application behavior, accessibility and acceptance against requirements.

Deliverable: connected systems and traceable test results.

We can start with a review of one process and a pilot with a clear scope. Tell me where development gets stuck.

// practical questions

Before we start

What does an agentic engineer do?

Designs and builds systems where AI agents use tools and carry out connected tasks. The work includes architecture, context management, permissions, testing and supervision of the result.

What can you help with?

Software development automation, multi-agent system design, bringing AI into an existing application, and connecting agents through APIs and MCP. A useful starting point is one process that is slow or hard to verify today.

Do we need to adopt the entire ecosystem?

The scope follows your environment. We can start with one integration or one part of the development process. The workshop shows my experience and approach; we choose tools to fit the project.

How do you manage quality and autonomy?

We define scope, permissions, acceptance criteria and approval points in advance. Tests and review verify a specific version. Deployment has its own checks in the target environment.
