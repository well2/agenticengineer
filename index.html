Kovárna

Svoje nástroje jsem pojmenoval podle kovárny. Ne kvůli romantice — protože agentic engineering je řemeslo: má postup, nástroje a kontrolu kvality. Tohle je můj výrobní cyklus.

01 · kovadlina

Anvil

issue → spec

Vykove ze syrového GitHub issue spec připravený k implementaci. Agenti čtou zadání proti reálnému kódu, hledají díry a nejasnosti — a každý zápis schvaluje člověk.

  • read-only analýza
  • human-in-the-loop

02 · výheň

Forge

issue → pull request

Orchestrační platforma: agenti projdou spec, implementaci, code review, validaci i CI smyčky — až po merge a kontrolu po něm. Žádné „věřte nám“: každý požadavek má svůj ledger.

  • 27stavový state machine
  • requirement ledger
  • 50+ CLI příkazů

03 · kalení

Temper

PR → důkaz

Self-healing testování v reálném prohlížeči. Když selektor ujede, agent pochopí původní záměr, test doběhne — a scénář se sám opraví, aby příště běžel deterministicky.

  • screenshot každého kroku
  • samoopravné scénáře

CogneraSpec

Spec-driven CLI, které drží agenty za slovo: každý požadavek má stabilní REQ-ID a ověřitelnou evidenci v testech. Drift mezi specem a realitou se měří, ne tuší.

AI Toolkit

Knihovna 59 příkazů a 25 skillů pro Claude Code a Codex — párované audity a opravy pro security, performance, a11y a další. Standardizace agentních workflow.

Meeting Agent

Záznam z meetingu → hotové GitHub issues. Gemini čte video včetně obrazovky, Claude píše issues v kontextu repozitáře, screenshoty se přiloží samy.

…a další: agent-system (orchestrace přes Telegram), MCP servery, invoiceAI.
