Kovárna

Svoje nástroje jsem pojmenoval podle kovárny. Ne kvůli romantice — protože agentic engineering je řemeslo: má postup, nástroje a kontrolu kvality. Tohle je můj výrobní cyklus.

01 · kovadlina

Anvil

issue → spec

Čte zadání proti skutečnému kódu. Najde nejasnosti a chybějící souvislosti dřív, než se začne implementovat. Změny zadání schvaluje člověk.

  • read-only analýza
  • human-in-the-loop

02 · výheň

Forge

issue → pull request

Řídí agenty od implementace přes code review až po testy a CI. Sleduje splnění požadavků, koordinuje opravy a ověřuje výsledek po merge.

  • code review
  • testy a CI
  • requirement ledger

03 · kalení

Temper

PR → důkaz

Testuje v reálném prohlížeči a zachycuje jednotlivé kroky. Když se rozhraní změní, agent pomáhá opravit scénář pro další opakovatelný běh.

  • screenshot každého kroku
  • samoopravné scénáře

Propojuje požadavky s kódem a testy. Každý má vlastní REQ-ID a ověřitelnou evidenci. Rozdíl mezi zadáním a výsledkem je vidět.

AI Toolkit
